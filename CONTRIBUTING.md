# Contributing to 53ON Harness

Thanks for helping. 53ON Harness is the open shell of 53ON on your Windows PC (MIT).

- **Questions and ideas:** open a [Discussion](https://github.com/53on/53on-harness/discussions).
- **Bugs:** open an issue with the bug template: your 53ON version (≡ › About), Windows version, what you did, what you expected and what happened.
- **Pull requests:** small and focused. Run `npm test` before sending; every suite must pass. Code and comments in English.
- **Security:** please report vulnerabilities privately through GitHub's *Report a vulnerability*, not in public issues.

The memory engine (MemoriaBios) is closed source and is not part of this repository.
